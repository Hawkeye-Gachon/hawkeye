# Design

Hawkeye 앱의 디자인 에셋과 문서를 관리하는 폴더입니다.

| 파일 | 내용 |
| --- | --- |
| [`hawkeye_design.fig`](hawkeye_design.fig) | 전체 화면 시안(Figma). Figma에서 **파일 가져오기(Import)** 로 엽니다. |

구현은 [`app/`](../app)에 있고, 시안의 색·글자·치수는 `app/app/src/main/java/com/personal/driverguard/ui/theme/Tokens.kt`에 토큰으로 옮겨 두었습니다.

## 디자인 방향

Hawkeye는 차량 센터 디스플레이에서 주행 중에 켜 두는 앱입니다. 그래서 세 가지를 기준으로 삼았습니다.

1. **차에 원래 있던 화면처럼 보일 것.** 현대자동차그룹 차량 인포테인먼트(Pleos Connect)의 디자인 언어를 따르고, 차량 내비 화면과 나란히 놓아도 이질감이 없게 했습니다.
2. **읽지 않아도 알 수 있을 것.** 운전자는 화면을 오래 볼 수 없습니다. 상태는 화면 가장자리의 색과 큰 문구 한 줄로 먼저 전하고, 자세한 내용은 그다음입니다.
3. **누르지 않아도 될 것.** 주행 중 조작은 음성과 자동 전환으로 끝나게 하고, 화면 터치는 정차 중에 쓰는 기능(설정, 리포트)에 모았습니다.

## 현대 디자인 시스템과 내비의 톤

| 항목 | 적용한 내용 |
| --- | --- |
| 서체 | **Asta Sans**(현대자동차그룹의 소프트웨어 회사 42dot이 만든 서체, SIL OFL). 큰 숫자와 제목은 Light, 버튼과 경고는 SemiBold로 씁니다. 굵은 영문 제목에만 Pretendard Bold를 보조로 씁니다. |
| 화면 규격 | 가로형 **1280 × 800dp** 한 장으로 그리고, 실제 디스플레이 크기에 맞춰 비율 그대로 확대·축소합니다. |
| 바탕 | 흰색 바탕 위에 옅은 회색(`#F6F6F9`) 카드. 차량 내비의 밝은 지도 화면과 같은 밝기대를 유지합니다. |
| 강조색 | 로고 남색(`#0B2A5C`) 하나. 주 버튼, 선택 상태, 차트의 최댓값에만 씁니다. |
| 경고색 | 주황(`#FF8A00`)은 전방 주시 이탈, 빨강(`#F62E24`)은 졸음에만 씁니다. 그 밖의 화면에는 쓰지 않습니다. |
| 형태 | 카드 반경 32dp, 버튼 반경 24dp의 둥근 사각형. 선 굵기 1.5의 선형 아이콘. |
| 터치 영역 | 기본 버튼 높이 72dp, 홈의 '관찰 시작'은 88dp, 가장 작은 버튼도 52dp입니다. |

내비의 톤을 유지한다는 것은 색만의 문제가 아닙니다. **지도와 길 안내는 앱에서 다시 그리지 않고 차량 내비에 그대로 맡깁니다.** 쉼터를 제안할 때 앱은 `현재 위치 → 쉼터 → 목적지` 순서만 한 줄로 보여 주고, 실제 경로와 안내는 운전자가 평소 보던 내비 화면에서 이어집니다. 같은 정보를 두 화면이 다르게 보여 주는 일을 피하기 위해서입니다.

## 화면 배치와 그 이유

### 왼쪽 장면 카드 + 오른쪽 시트

주행과 관련된 모든 화면은 같은 두 칸 구성입니다.

```text
┌──────────────────────────┬───────────────────┐
│                          │  그림             │
│   장면 카드 (688dp)      ├───────────────────┤
│   카메라 영상 · 지도     │  상태 · 큰 문구   │
│                          │  부가 정보        │
│                          │  [ 버튼 ]         │
└──────────────────────────┴───────────────────┘
                              시트 (520dp)
```

- **왼쪽 장면 카드**는 '지금 보이는 것'입니다. 설정·관찰 중에는 운전자 카메라 영상, 리포트에서는 주행 경로가 들어갑니다.
- **오른쪽 시트**는 '지금 상태와 할 일'입니다. 위에서부터 그림, 상태 문구, 부가 정보 순이고, 버튼은 항상 시트 맨 아래에 붙습니다.

이렇게 고정한 이유는 다음과 같습니다.

- **위치를 외우게 하려고.** 관찰 중, 경고, 쉼터 제안으로 화면이 바뀌어도 틀은 그대로이고 시트 안의 내용만 바뀝니다. 운전자는 문구가 어디에 뜨는지, 버튼이 어디 있는지 다시 찾지 않아도 됩니다.
- **경고 순간에 화면이 흔들리지 않게.** 경고가 떠도 배치가 움직이지 않으므로, 달라진 것(색과 문구)만 눈에 들어옵니다.
- **행동은 하나만.** 시트의 주 버튼은 하나이고(남색), 보조 버튼은 그 아래에 덜 눈에 띄는 형태로 둡니다. 급한 순간에 고를 것이 없게 했습니다.

### 가장자리 빛으로 전하는 경고

경고는 화면 전체 테두리의 빛으로 먼저 전합니다.

| 상태 | 가장자리 | 시트 문구 |
| --- | --- | --- |
| 관찰 중 | 없음 | "관찰 중", 경과 시간, 부주의·졸음 횟수 |
| 전방 주시 이탈 | 주황, 고정 | "전방을 봐 주세요" |
| 졸음 | 빨강, 천천히 깜빡임 | "졸음이 감지됐습니다" |
| 쉼터 제안 | 옅은 빨강 | "○○ 졸음쉼터를 경유지로 추가할까요?" |

- 운전자는 전방을 보고 있으므로 화면은 **주변 시야**에 들어옵니다. 주변 시야에서는 글자보다 색과 밝기 변화가 먼저 보이기 때문에, 화면을 쳐다보지 않아도 경고를 알 수 있습니다.
- 단계가 올라갈수록 색(주황 → 빨강)과 움직임(고정 → 깜빡임)이 강해집니다. 졸음 뒤의 쉼터 제안은 빛을 옅게 낮춰, 경고에서 제안으로 넘어갔음을 알립니다.
- 색만으로 전하지 않습니다. 같은 내용을 아이콘, 44~48sp 문구, 음성 안내로 함께 전합니다.

### 카메라 카드

- 운전자 영상 위에 어두운 막이나 블러를 씌우지 않습니다. 운전자가 '카메라가 나를 제대로 보고 있는지'를 한눈에 확인할 수 있어야 하기 때문입니다. 영상 위 글자는 그림자로 읽기 쉽게 했습니다.
- 감지 수치(눈 뜬 정도, 머리 방향)는 얼굴을 가리지 않도록 카드 아래쪽에 한 줄로 둡니다.
- 차량이 실제로 한 조치(음성 안내, 무드등, 공조, 창문, 시트 통풍)는 카드 왼쪽 위에 차례로 쌓입니다. 차가 왜 갑자기 바람을 세게 트는지 운전자가 알 수 있게 하기 위해서입니다.
- '관찰 종료'는 관찰 중 어느 화면에서나 카드 오른쪽 위 같은 자리에 있습니다.

### 쉼터 제안

- 제안은 화면과 함께 **음성으로 묻고**, "응"이라고 답하면 경유지로 추가합니다. 버튼을 누르지 않아도 됩니다.
- 응답이 없으면 스스로 관찰 화면으로 돌아갑니다. 운전자가 닫기 버튼을 누르러 손을 뻗을 일이 없습니다.
- 경유지가 가득 찼거나, 내비가 응답하지 않거나, 쉼터를 찾지 못한 경우를 각각 별도 화면으로 그렸습니다. 이때는 그림을 회색으로 낮춰 정상 제안과 구분합니다.

### 리포트와 통계

- 정차 중에 보는 화면이므로 정보 밀도를 높였습니다. 일간·주간 통계는 화면 전체를 쓰는 넓은 카드 한 장입니다.
- 주행 리포트는 주행 화면과 같은 두 칸 구성을 써서, 왼쪽에 경로와 감지 위치를, 오른쪽에 요약 숫자를 둡니다.
- 막대 차트에서 '관찰하지 않은 날'(점선)과 '관찰했지만 0회인 날'(짧은 막대)을 다르게 그립니다. 기록이 없는 것을 안전했던 것으로 오해하지 않게 하기 위해서입니다.
- 숫자는 굵게, 단위는 가늘게 써서 숫자가 먼저 읽히게 했습니다.

### 글자

- 한 화면에서 가장 큰 글자가 가장 중요한 정보입니다. 관찰 중에는 경과 시간(76sp), 경고 중에는 경고 문구(44~48sp)입니다.
- 한국어는 어절 단위로만 줄을 바꿉니다. 낱말 중간에서 끊기면 짧게 훑어볼 때 읽기 어렵습니다.
- 변하는 숫자(시간, 수치)는 고정폭 숫자를 써서 값이 바뀌어도 글자가 흔들리지 않습니다.

## 화면 구성

시안에는 아래 화면과 각 화면의 상태별 변형이 들어 있습니다.

| 구간 | 화면 |
| --- | --- |
| 시작 | 스플래시, 로그인(실패 포함), 회원가입(입력 오류 포함), 약관 동의 |
| 홈 | 홈(이전 기록, 이번 주 요약) |
| 출발 전 | 보는 방향 설정: 설정 전, 설정 완료, 얼굴 확인 불가 |
| 주행 중 | 관찰 중, 전방 주시 경고, 졸음 경고 |
| 쉼터 | 경유지 추가 제안(졸음 후 / 부주의 3회 / 기존 경유지 있음 / 목적지 없음), 경유지 가득 참, 내비 연동 실패, 쉼터를 찾지 못함, 추가 완료, 쉼터 도착 |
| 종료 | 관찰 종료 확인, 이번 주행 리포트 |
| 기록 | 일간 리포트(날짜 선택, 기록 없음 포함), 주간 통계(졸음 0회 포함) |
